Code lookups for AI agents, measured

We ran 787 agents on one Python repository and measured what each way of finding code costs in tokens and turns, and how often the answers were right.

What it does for an agent

  • Finds definitions and callers in one callAn agent asks once and gets where a function is defined, its parameters and every function that calls it.
  • Searches code by meaningAn agent describes a job in words and gets the function that does it.
  • Shows what a change touchesBefore editing, an agent sees what depends on the code it is about to change.
  • Remembers findings across sessionsWhat an agent has already worked out does not have to be found again next time.

The study measures the first two. The other two are not covered by the measurements on this site.
