Local index token benchmark

An agent re-reads its whole context on every turn, so the number of turns is what a lookup costs. A local index is worth having when it gives the answer in fewer turns.

  • Which lookup method is cheapest?11 methods are level at about 130k tokens and 2.0 turns for three lookups on the cheapest tier, 64% fewer than no index (365k). The build that ships, Shipped: lx ask, default index, is one of them.The leaderboard
  • Does an orchestrator pay for itself?It buys accuracy at a price. On the cheapest subagents 48 of 48 orchestrated runs ended fully correct, against 38 of 43 for three subagents with nobody reviewing, and a run cost about 95 times one agent.Orchestration
  • Do token-goat's hooks help?Not on these lookups. Token use stayed inside the spread between repeats, and with no index 5 of 9 runs ended fully correct with the hooks against 13 of 17 without, because a redaction marker hid a line the lookup needed.Hooks
  • How do I install it?One file: python INSTALL.txt. Rules, three agents, a session hook and the lx command, for Claude Code, Codex and Copilot.Setup

Leaderboard

One row per method, fewest tokens first. Each row is the mean of the complete runs of that method, and the Runs column says how many that is. Pick a setup and a model tier. A model tier is a class of model, from the lightest (C) to the strongest (A). The row tagged control used no index, only the search and read tools every agent has. Reruns made to test token-goat's hooks are left out of this list and compared on the Hooks page.
