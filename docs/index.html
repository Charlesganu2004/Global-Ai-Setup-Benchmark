Local index token benchmark

An agent re-reads its whole context on every turn, so the number of turns is what a lookup costs. A local index is worth having when it gives the answer in fewer turns.

Leaderboard

One row per method, fewest tokens first. Each row is the mean of the complete runs of that method, and the Runs column says how many that is. Pick a setup and a model tier. A model tier is a class of model, from the lightest (C) to the strongest (A). The row tagged control used no index, only the search and read tools every agent has. Reruns made to test token-goat's hooks are left out of this list and compared on the Hooks page.
