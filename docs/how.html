How it was measured

What was counted, how it was priced, and what this test cannot tell you.

    Terms used on this site

    Method
    The set of search commands an agent was allowed to use. Everything else stayed the same.
    Model tier
    A class of model, not a version: C is the lightest, B the fast coding class, A the strongest.
    Run
    One attempt at the three questions, by one agent or by a group of them, graded by a script.
    Turn
    One request to the model. Every turn re-reads everything before it, which is why turns decide the cost.
    Start-up context
    What an agent's first request holds before it has done anything: the system prompt, tool definitions, skills and rules.
    Re-read
    Tokens read back from the cache on later turns.
    Added
    New context on later turns: tool results and the agent's own earlier output.
    Cache warm
    The cost of a run when its start-up context was already in the cache, because another agent ran in the last five minutes.
    Cache cold
    The cost of the same run when the start-up context had to be written to the cache first.
    Mean score
    The average grade of the three answers, where a partly right answer earns part credit. A run is fully correct only when all three are fully right.
