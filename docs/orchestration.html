Orchestrator and subagents

An orchestrated run has three parts: the strongest model writes three briefs, three subagents answer one question each, and a reviewer checks the three answers and returns the final ones.

The tier named on this page is the tier of the subagents. The orchestrator is always the strongest model, except under "Who reviews, and with what" and in the run list below it, where the reviewer is varied on purpose. Costs are at list prices with the start-up context already cached.

    What the review changed

    Each run asks three questions, so answers are counted per question. An answer counts as wrong when it is not fully right: a corrected answer was wrong and came out fully right, a broken one was fully right and came out wrong. The two score columns are mean scores, where a partly right answer earns part credit, so one wrong answer in three can still read 92%.
